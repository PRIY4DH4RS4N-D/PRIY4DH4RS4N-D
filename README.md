<details open>
<summary><h3>🏆 Real-Time Embedded AI Vision Assistant for the Visually Impaired</h3></summary>

<table>
<tr><td>

> **AI deployed onto constrained embedded hardware — not a desktop ML project.**

**Problem** — Enable real-time visual scene understanding and assistive output for visually impaired users, running entirely on a resource-constrained microcontroller with no cloud dependency.

**Hardware** — Renesas EK-RA8P1 · Arm Cortex-M85 · Arm Ethos-U NPU · 512-Mbit OSPI Flash

**Firmware / Software** — μT-Kernel 3.0 RTOS · Renesas FSP · e² studio · target-hardware flashing and verification

**Interfaces** — Camera input · audio output · on-chip OSPI Flash · debug via e² studio

**Architecture**
```
Camera Input
     ▼
┌─────────────────┐
│   YOLO-Tiny     │  ← Object Detection
└────────┬────────┘
         ▼
┌─────────────────┐
│     OCR         │  ← Text Recognition
└────────┬────────┘
         ▼
┌─────────────────┐
│  Neural TTS     │  ← Speech Synthesis
└────────┬────────┘
         ▼
  Assistive Audio Output
```

**Engineering Challenge** — Running a 3-model parallel Edge AI pipeline (YOLO-Tiny + OCR + Neural TTS) concurrently on a Cortex-M85 under RTOS scheduling constraints, with all models optimized for embedded inference on the Ethos-U accelerator.

**Result** — Functional real-time assistive system deployed on target hardware with 3-model concurrent inference pipeline running under μT-Kernel 3.0 RTOS.

</td></tr>

<!-- ────────────────────────────────────────────────────────────────────
     PROJECT 4: WaferWise
     ──────────────────────────────────────────────────────────────────── -->

<details open>
<summary><h3>🔬 WaferWise: Hardware-Aware AI for Semiconductor Inspection</h3></summary>

<table>
<tr><td>

> **Memory constraints + model optimization + embedded deployment.**

**Problem** — Deploy a real-time semiconductor wafer defect classification system on a resource-constrained embedded processor, proving that production-grade inspection can run on the edge.

**Hardware** — NXP i.MX RT1170

**Software** — INT8 MobileNetV3 · TensorFlow Lite Micro · hardware-aware quantization

**Architecture**
```
Wafer Image Input
       ▼
  INT8 MobileNetV3
       ▼
  11-Class Defect Classification
       ▼
  Real-Time Inspection Output
```

**Engineering Challenge** — Compressing a MobileNetV3 model from 2.0 MB → 694 KB (65% reduction) while maintaining 91.25% classification accuracy across 11 defect classes, fitting within 2.57% Flash and 1.69% SDRAM of the target MCU.

**Key Metrics**

| Metric | Value |
|--------|-------|
| Classification Accuracy | **91.25%** |
| Model Size Reduction | **2.0 MB → 694 KB (65%)** |
| Embedded Executable | **1.76 MB** |
| Flash Utilization | **2.57%** |
| SDRAM Utilization | **1.69%** |
| Defect Classes | **11** |

</td></tr>
</table>
</details>
